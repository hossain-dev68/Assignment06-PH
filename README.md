# FitLog — Workout Library

FitLog is a responsive dark-themed workout companion built with Next.js. Users can browse workouts, open detailed exercise pages, add lifts to today's plan, save workouts for later, and track completed exercises.

## Technologies Used

- Next.js 16 App Router
- React 19
- TypeScript
- Tailwind CSS 4
- DaisyUI
- React Toastify
- Browser localStorage

## Key Features

1. Responsive workout library for mobile, tablet, and desktop.
2. Workout detail pages with equipment, difficulty, sets, reps, calories, rating, and instructions.
3. Today's Plan with a maximum of five workouts.
4. Saved workouts with live navbar counters.
5. Mark as Done and remove actions with toast notifications.
6. Sort workouts by duration, calories, or rating.
7. localStorage persistence across page reloads.
8. Custom 404 page and loading states.
